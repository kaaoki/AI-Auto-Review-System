# 文書自動レビューツール（Generative AI Document Reviewer）

Gemini API を使い、複数フォーマット（Markdown / Word / Excel / PDF）の文書をまとめて自動レビューし、指摘結果を Excel レポートとして出力するツールです。

## 背景・課題

これまで Access / Excel VBA・SQL Server・RPA を使い、業務システムのデータ連携や部署間の集計業務を自動化してきました。生成AIの実務活用力を示すため、「人がチャットで都度チェックする」のではなく、**固定のレビュー観点をプロンプトとして設計し、複数ファイルを自動でまとめてレビューする仕組み**として本ツールを作成しました。

入稿業務のレビューや、社内文書のチェック工程を想定した題材です。

## できること

- フォルダを指定するだけで、中の対象ファイルをまとめて自動レビュー
- 対応フォーマット：`.txt` `.md` `.docx` `.xlsx` `.xlsm` `.pdf`
- レビュー観点（プロンプトで固定）
  - 誤字脱字
  - 日付・数値などの事実関係の誤り
  - 文章内での矛盾（前半と後半で方針や結論が食い違っている箇所など）
  - フォーマット・表記ゆれ
- レビュー結果を **JSON構造化出力** で受け取り、Excelレポート（該当箇所・指摘内容・修正提案・重要度）として整形
- 全ファイルの結果を1つのExcelブックに集約（サマリーシート＋ファイルごとの詳細シート）
- 1ファイルでエラーが起きても処理全体を止めず、そのファイルだけ記録して次に進む

## 使用技術

| 分類 | 使用技術 |
|---|---|
| 言語 | Python |
| 生成AI API | Google Gemini API（`google-genai` SDK） |
| ファイル読み込み | `python-docx`（Word）, `openpyxl`（Excel）, `pdfplumber`（PDF） |
| レポート出力 | `openpyxl` |

## セットアップ

```bash
pip install google-genai openpyxl python-docx pdfplumber
```

### APIキーの取得・設定

1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、Googleアカウントでログイン
2. 「Get API key」からキーを発行（無料枠あり）
3. 環境変数に設定

```bash
# macOS / Linux
export GEMINI_API_KEY="あなたのAPIキー"

# Windows (コマンドプロンプト)
setx GEMINI_API_KEY "あなたのAPIキー"
```

> **注意：** APIキーはコードに直接書き込まないでください。本ツールは環境変数からのみキーを読み込む設計にしており、リポジトリ内にキー情報は一切含まれません。実行する方は、各自でご自身のAPIキーを取得・設定してください。

## 使い方

```bash
# フォルダ内の対象ファイルをまとめてレビュー
python3 review_tool.py input/

# 出力先を指定する場合
python3 review_tool.py input/ output/my_report.xlsx

# 単一ファイルのみレビューする場合
python3 review_tool.py input/report_sample.md
```

## サンプル

`input/` に、意図的に問題を仕込んだダミーの業務文書を3種類同梱しています（すべて架空のデータです）。

| ファイル | 仕込んだ問題 |
|---|---|
| `report_sample.md` | 存在しない日付、文章内の方針の矛盾、表記ゆれ |
| `nyuko_irai.docx` | 存在しない日付、本文と表内の数値の食い違い |
| `keihi_seisan.xlsx` | 実行環境によって検出内容が変わる自由記述形式（実際には合計未記入等を指摘） |

`output/review_report_sample_result.xlsx` は、上記サンプルを実際に実行して得られたレビュー結果の実物です（加工なし）。

## 工夫した点・つまずいた点

- 初期のプロンプトでは「文章内での矛盾」の定義が曖昧で、明確な矛盾（例：慎重な計画と積極投資目標の併記）を見逃すことがありました。プロンプトに具体例を追記し、再テストして検出精度を改善しました。
- 逆に、契約件数増加と売上減少の併記など、一見矛盾に見えて実際には論理的に成立しうる記述については、AIが正しく「矛盾ではない」と判断するケースもあり、テストケース自体の妥当性を見直す必要がありました。
- Excelファイルを `data_only=True` で読み込むと数式セルの値が取得できない場合があり、その挙動を逆手にとって「未計算・未入力」の指摘に活用しています。
